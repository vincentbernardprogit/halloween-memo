# Halloween Memo

Project type: Personal Project<br>
Platform: Web<br>
Genre: Puzzle<br>
Subgenre: Memory<br>
Technologies: HTML, CSS, JavaScript, React v18.2.0, Git, GitHub

A casual memory game built with React.

How to play:
1. The dealer and you get the cards from the beginning, the rules are same with the rules of Blackjack.
2. Click the button Hit to draw a new card.
3. Click the button Stay to confirm your final cards.
4. The game will set the result at the bottom of the screen.
5. You can refresh the browser to start a new game.

Note:
1. Do not need to download or install this game in local to play it.
2. Click the link below to play this game directly.<br>
