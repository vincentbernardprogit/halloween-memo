# Halloween Memo

Project type: Personal Project<br>
Platform: Web<br>
Genre: Puzzle<br>
Subgenre: Memory<br>
Technologies: HTML, CSS, JavaScript, React v18.2.0, Git, GitHub

A casual memory game built with React.

How to play:
1. The game starts automatically when you open it on the browser.
2. Click the card to reveal the hidden image of the card.
3. Click the other card to reveal it.
4. If both cards have the same image, then they stay revealed because they are matched.
5. Turns shows how many turns you need to finish the game, turn = matching 2 revealed cards regardless of the cards are matched or not.
6. If you already finished the game, you can click the button New Game to start a new game.

Note:
1. Do not need to download or install this game in local to play it.
